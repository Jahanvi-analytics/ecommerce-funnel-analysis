# Customer Journey Funnel Leak Analysis
### E-Commerce Dashboard | Power BI | 30,000 Records

## Project Overview
An end-to-end business analytics project analyzing customer 
drop-off points across the e-commerce purchase funnel — 
from product view to final purchase.

## Tools Used
- Python — synthetic dataset generation (30,000 records)
- Power BI — interactive dashboard with 2 pages
- DAX — 10+ custom measures

## Dataset
- 30,000 sessions across 21 product categories
- 8,000 unique users across 10 Indian cities
- Full year 2024 data (Jan–Dec)
- 23 columns covering funnel stages, demographics, revenue

## Dashboard Features
**Page 1 — Main Dashboard**
- 6 KPI cards (Sessions, Revenue, Conversion Rate etc.)
- Customer Journey Funnel chart
- Monthly/Quarterly toggle with bookmarks
- Sessions by Traffic Source, Device, Age Group
- Revenue by Category and City

**Page 2 — Performance Insights**
- Dynamic revenue threshold slider
- Conditional bar chart (red = below target, green = above)
- Categories Above Threshold KPI card
- Navigation buttons between pages

## Key Insights
- Overall Conversion Rate: 28.4%
- Cart Abandonment Rate: 56%
- Laptop drives highest category revenue (₹29.7M)
- Organic Search brings highest session volume
- Desktop has highest conversion rate (29%)
- Q3 2024 peaked in total sessions
